## Sobre mí

Soy Lic. en Sistemas de Información de las Organizaciones (FCE-UBA) y actualmente curso Desarrollo Web Full Stack, profundizando mis conocimientos en programación y tecnología.

Me interesa comprender cómo funcionan los procesos dentro de una organización, entender el porqué detrás de ellos y encontrar oportunidades de mejora. A la vez, me interesa la tecnología y la programación como herramientas para transformar esas oportunidades en soluciones concretas.

Soy una persona curiosa, con interés por los datos y por encontrar formas de optimizar procesos, aprovechar mejor los recursos y generar información que facilite la toma de decisiones. Me motiva especialmente combinar una mirada de negocio con conocimientos técnicos para crear soluciones que aporten valor.

## Proyectos

### FOCO — Webapp de productividad visual

*Fundación Pescar · 2026 – Actualidad*

Aplicación web colaborativa de productividad visual desarrollada en equipo. Cuenta con un canvas interactivo para organizar información, temporizador Pomodoro, tracker de hábitos y chatbot de onboarding.

Participé en el desarrollo de funcionalidades de frontend y backend, incluyendo la implementación de drag & drop para la gestión de notas, un sistema de personalización de interfaz con 7 paletas de colores y modo oscuro, persistencia de las preferencias del usuario en Supabase, funcionalidades CRUD para la gestión de usuarios y tablero, y endpoints REST para la gestión de bloques y notas.

El proyecto se desarrolló utilizando GitFlow, Conventional Commits y pull requests con revisión de código.

**Tecnologías:** JavaScript · Node.js · Express · PostgreSQL · Supabase · Tailwind CSS · SortableJS · Git

🔗 [Repositorio Backend](https://github.com/ImaaValenzuela/foco.backend) · [Repositorio Frontend](https://github.com/ImaaValenzuela/foco.frontend)

### Consultoría IT — Proyecto académico

*Universidad de Buenos Aires · 2026*

Proyecto de análisis y propuesta de transformación de procesos administrativos y de tesorería para una empresa agroindustrial.

Se realizó el relevamiento de procesos y requerimientos, la identificación de brechas y la evaluación de proveedores mediante RFI/RFP. El proyecto culminó con una propuesta de automatización mediante una solución SaaS, considerando las necesidades del negocio y las alternativas tecnológicas disponibles.
